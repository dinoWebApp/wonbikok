# 원비콕 코드 리뷰 체크리스트

## 이 스킬의 목적

Reviewer가 원비콕 구현 코드를 체계적으로 검증하기 위한 레이어별 점검 항목을 제공한다. 모든 지적은 **Rule ID + 파일:라인 + 수정 제안**을 동반한다.

## 우선순위 원칙

1. 비즈니스 로직 정합성(Rule ID 위반) > 2. 데이터 무결성·보안 > 3. 아키텍처 준수 > 4. 성능. 코드 스타일(RuboCop 영역)은 지적하지 않는다.

## 판정 기준

- `APPROVED`: BLOCKER 0 + CRITICAL 0 (WARNING는 기록만)
- `CHANGES_REQUESTED`: BLOCKER 또는 CRITICAL 존재 → 수정 후 재검증 범위 명시
- BLOCKER 발견 즉시 나머지는 요약만 하고 보고(루프 최소화)
